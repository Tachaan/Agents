# V-Model Delivery Rules

- Confirm the active lifecycle phase before editing an artifact.
- Read the latest upstream artifact and recent changes first.
- Keep stable IDs and bidirectional traceability across requirements, designs,
  implementation, tests, results, and evidence.
- When an upstream artifact changes, perform change-impact analysis before
  modifying downstream work.
- Do not mark a phase complete while mandatory artifacts, test evidence, or
  blocking-review resolutions are missing.
- Record assumptions and unresolved decisions explicitly instead of silently
  inventing requirements.
- Prefer project-specific commands and conventions over generic examples in the
  skills.
