# Run a Quality Gate

Review the current phase deliverables against:

- Upstream requirements and design inputs
- Required artifact structure and completeness
- Bidirectional traceability
- Testability and acceptance criteria
- Security and non-functional concerns
- Execution results and evidence, when applicable
- Unresolved findings from prior reviews

Return actionable findings with severity, artifact, location, rationale, and
required action. End with `PASS` or `FAIL` and state the exact blocking items.
