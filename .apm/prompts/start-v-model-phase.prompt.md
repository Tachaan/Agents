# Start a V-Model Phase

Determine the requested lifecycle phase and:

1. Identify its required upstream inputs and paired verification phase.
2. Inspect the latest relevant artifacts and changes.
3. Define the work scope, exclusions, assumptions, risks, and open decisions.
4. List deliverables with stable identifiers and expected locations.
5. Define measurable completion gates and required review evidence.
6. Execute the phase using the matching skill.

If the requested phase or expected artifacts are ambiguous, stop before editing
and request the missing decision.
